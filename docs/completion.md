# Command completion

Envirou ships with tab completion for bash, zsh, fish and PowerShell,
generated by the built-in `envirou completion` command.

Note: `envirou install` does not set up completion; the steps below are
manual. Completion is registered for the `envirou` binary - see the end of
this page for enabling it on the `ev` wrapper as well.

Run `envirou completion SHELL --help` for shell-specific details.

## Bash

Requires the [bash-completion](https://github.com/scop/bash-completion)
package to be installed and enabled.

Load for every session by adding to `~/.bashrc` (or `~/.bash_profile` on macOS):

```bash
source <(envirou completion bash)
```

Or install system-wide:

```bash
# Linux
envirou completion bash | sudo tee /etc/bash_completion.d/envirou > /dev/null
# macOS with Homebrew bash-completion
envirou completion bash > $(brew --prefix)/etc/bash_completion.d/envirou
```

## Zsh

Add to `~/.zshrc`:

```zsh
source <(envirou completion zsh)
```

Or install into a directory on your `$fpath`:

```zsh
envirou completion zsh > "${fpath[1]}/_envirou"
```

If completion has never been enabled in your zsh, also add
`autoload -U compinit; compinit` to `~/.zshrc`.

## Fish

```fish
envirou completion fish > ~/.config/fish/completions/envirou.fish
```

## PowerShell

Add to your PowerShell profile (path shown by `echo $PROFILE`):

```powershell
envirou completion powershell | Out-String | Invoke-Expression
```

## Completing the `ev` wrapper

The generated scripts complete the `envirou` command. To get the same
completion for the `ev` shell function, add after the source line:

```bash
# bash
complete -o default -F __start_envirou ev
```

```zsh
# zsh
compdef _envirou ev
```
